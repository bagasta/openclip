Akses YouTube · opsional

Jika YouTube meminta verifikasi, login dan buka videonya di browser pilihanmu. yt-dlp memilih profil secara otomatis. Saat unduhan dijalankan, cookie profil dibaca; hanya cookie YouTube yang dipakai aplikasi. Gunakan file cookie jika akun pada profil yang terbaca berbeda.

Akses YouTube

Login YouTube dan buka video sumber di browser pilihanmu terlebih dahulu. Saat unduh dijalankan, yt-dlp membaca cookie profil yang dipilih otomatis; hanya cookie YouTube yang dipakai aplikasi. Jika akun yang terbaca berbeda, gunakan file cookie dari profil yang benar.

Maksimal 2 MB. Kosongkan untuk memakai file yang sudah disimpan. Jika belum ada, pilih file terlebih dahulu.

Cookie adalah sesi login; jangan dibagikan. File disimpan privat di laptop, tidak masuk ekspor, dan tidak dikirim ke OpenRouter. Pilih Tanpa sesi login lalu simpan untuk menghapus file cookie tersimpan.

Panduan ekspor cookie YouTube. Jika browser gagal dibaca, gunakan file cookies.txt dari profil yang sudah login.

Akses YouTube

Login dilakukan di situs YouTube/Google dalam jendela browser khusus OpenClip. Sesi disimpan di laptop dan dipakai untuk unduhan saat kamu memilih Gunakan sesi. Password diisi langsung di browser tersebut.

Selesaikan login dan pastikan video sumber bisa diputar. Tutup jendela browser itu, lalu kembali ke sini. OpenClip memakai profil khusus tersebut agar sesi tidak tertukar dengan profil browser lain.

Sesi baru dibaca saat unduh dijalankan. Untuk keluar akun, buka kembali jendela login ini dan gunakan menu akun YouTube. File video lokal tetap bisa diunggah jika akses YouTube ditolak.
