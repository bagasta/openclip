# OpenClip Local

Direction: a local editing workbench based on the observed OpusClip workflow.
Dark charcoal surfaces support reviewing video without a bright page around it.
Lime marks the primary action and selected state, following the supplied product reference.
Use system sans-serif fonts so the application makes no font network requests.
Composition: a compact project rail, source/settings column, and clip review area.
Show real job stages and actual exported files. Never populate an empty library with fake clips or scores.
Score labels explicitly identify local ranking rather than claiming viral probability.
Controls have visible labels, keyboard focus, 44px targets, and responsive stacking.
Animation is limited to progress and feedback, and honors reduced motion.
No landing page, marketing metrics, gradients, external images, or inactive navigation.
